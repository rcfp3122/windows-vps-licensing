## Windows VPS 为什么贵：授权费才是大头

答案很简单：贵在 Windows Server 授权费。市场行情大约每月 10–20 美元，再加上 Windows 本身对硬件的更高要求——系统盘至少留 20GB，内存 2GB 起步、4GB 以上才舒服。这几项都是 Linux VPS 不需要承担的。

授权费的收法有两种，这也是最容易踩坑的地方：

- **打包进月费**。Hostinger 的 Windows 1（2核4G/100GB NVMe，$10.99/月）属于这种，页面报多少付多少；Ultahost、ScalaHosting 也采用授权包含的模式。
- **先报裸机价，结账时另加授权**。Contabo 页面价 $4.95/月，Windows 授权另加 $4.99，实际每月约 $9.94；Vultr 要在套餐外再加 $16/月授权费；IONOS 把授权按使用时长计费；OVHcloud 得进配置器才能看到 Windows 总价。多家评测提醒过同一件事：只看定价页第一个数字会低估成本，要按结账页的最终总价来比。

续费价是第二笔账。GoDaddy 首期 $8.99/月，但绑定三年合约，续费涨到 $11.99/月，第二年起年支出约 $143.88；Hostwinds 的 $14.94 是促销价，常规价 $22.99/月。反过来，InterServer 明确按固定价格续费。下单前把前两年的支出都算出来，比盯着首月价格有意义得多。

### 在 RackNerd 上装 Windows 的流程和易错点

流程不复杂，但每步都别省：

1. 下单选好机房和套餐，等开通邮件。
2. 进控制面板挂载 Windows ISO——可以用微软官方的评估版镜像，也可以先装 Linux 再用 DD 方式写入现成镜像。
3. 进 VNC 控制台完成安装。Windows Server 首次安装加上打补丁通常要 30–90 分钟，中途别重启。
4. 装完先测激活和 RDP 能不能连，确认没问题再部署应用。
5. 给系统盘留足空间，Windows 本身就吃掉约 20GB，2.5GB 档的 40GB SSD 属于刚好够用，别再塞大文件。

几个易错点：镜像要选对，桌面版和 Server 版对内存的要求差很多；RDP 的 3389 端口不要对全网裸开，改端口加防火墙白名单是基本操作；装完第一件事做快照或备份，Windows 更新偶尔会把系统弄挂，有备份才不怕。

再提醒一次前提：RackNerd 不提供 Windows 授权和 Windows 技术支持，评估版 ISO 有 180 天期限，长期生产环境需要正规授权。看完这段觉得麻烦的话，退回路线A更合适。

已有环境可以继续跑，但主流支持已于 2026 年 10 月 13 日结束。新部署建议直接上 Server 2025。
